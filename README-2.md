- Scroll-triggered reveal animations
- 3D card tilt on hover

## Deploy to GitHub Pages

```bash
# 1. Go to github.com → New Repository → name it "portfolio" → Public

# 2. In your portfolio folder:
git init
git add .
git commit -m "launch: portfolio v1"
git remote add origin https://github.com/DOREE20/portfolio.git
git branch -M main
git push -u origin main

# 3. GitHub → Settings → Pages → Source: main / root → Save
# Live at: https://DOREE20.github.io/portfolio
```
